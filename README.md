# Pavilion Hoops

A real-time pixel-art isometric diorama of a 3×3 basketball tournament played on the
half-court of an old parquet pavilion. Single-file HTML page built with three.js.

Status: work in progress — see `index.html`.

## Run

Open `index.html` in a browser (or via GitHub Pages once the first build lands).
